# 思源黑体

本目录随应用提供 Adobe 官方思源黑体简体中文可变网页字体，避免依赖远程字体服务或用户已安装的字体。

- 项目：[adobe-fonts/source-han-sans](https://github.com/adobe-fonts/source-han-sans)
- 原文件：`release/Variable/WOFF2/OTF/Subset/SourceHanSansCN-VF.otf.woff2`
- 本地文件：`SourceHanSansCN-VF.woff2`，保留原始二进制内容。
- 授权：SIL Open Font License 1.1，全文见同目录 `OFL.txt`。

字体由 `/assets/fonts/` 本地提供，开发服务和 Python 服务提供的生产构建使用同一路径。
